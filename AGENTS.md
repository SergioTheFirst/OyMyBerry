# Agent Instructions

## Tech Stack
- **Frontend**: HTML5 + CSS3 (vanilla, custom properties) + vanilla ES6
- **Dev Server**: Python 3 `http.server` with custom POST handlers
- **Hosting**: GitHub Pages (static)
- **Fonts**: Cormorant Garamond (display/logo) + DM Sans (body/nav)
- **No build tools, no frameworks, no package manager**

## File-Scoped Commands
| Task | Command |
|------|---------|
| Start dev server | `python server.py` or `server.bat` (Windows) |
| Edit config | Edit `config.json` directly, or open `http://localhost:8000/admin.html` |

## Project Conventions

### Content Pattern (`data-config`)
All dynamic text lives in `config.json`. HTML elements reference keys via `data-config` attribute:
```html
<span data-config="site.tagline">Сладкие моменты, созданные дома</span>
```
`js/main.js` loads `config.json` and injects values at runtime via `applyConfig()`.

### Adding Gallery Works
1. Drop images into `works/images/`
2. Append entry to `works/works.json`
3. Or use local admin panel (`admin.html`) while `server.py` is running

### CSS Conventions
- Design tokens in `:root` custom properties
- Mobile-first with explicit desktop breakpoints (`@media (min-width: 1024px)`)
- `animate-on-scroll` class triggers IntersectionObserver fade-in
- Hero section: `justify-content: flex-start` (text LEFT), `align-items: center`

### Critical Files
- `config.json` — single source of truth for ALL text: site, about, FAQ, contacts, nav, footer, categories, SEO
- `works/works.json` — gallery data (auto-generated by server)
- `faq.html` — 6 Q&A accordions via `data-config="faq.q1"` etc.; FAQPage JSON-LD built dynamically from `CONFIG.faq` at runtime
- `admin.html` (local-only) — page-based config sections (Главная, О проекте, FAQ, Контакты, Навигация, etc.); FAQ fully editable; `site.updated` date auto-stamped by server on save
- `css/style.css` — design system; edit with care (no preprocessor)
- `js/main.js` — core logic; exposes `window.CONFIG` for dynamic JSON-LD schema builders

### Excluded from Git (`.gitignore`)
- `*.py`, `*.bat`, `admin.html`, `secrets.json`, `__pycache__/`
- Server and admin are local-only, never deployed to GitHub Pages
